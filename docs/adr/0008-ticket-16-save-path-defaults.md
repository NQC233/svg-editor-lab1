# Ticket 16 文件路径与 save 提交语义

Status: accepted (2026-10-25)

Ticket 16 依赖 C1 中尚未逐条确认的 UTF-8 与相对路径默认。用户于 2026-10-25 确认：文件按 UTF-8 读取和写出；相对路径相对于进程当前工作目录解析。

本 ADR 同时确认 `save` 的提交边界：

- `save [file.svg]` 有参数时使用参数，无参数时使用会话当前路径；两者都不存在时报 `no file path; use save <file.svg>`。
- 写出成功后才更新当前路径；随后由既有文档命令协议清空并锁定撤销/重做历史。
- 参数错误、无路径或文件写入失败时，不改变文档、当前路径或历史。
- 会话保存用户提供的路径文本，不主动转换为绝对路径；相对路径在写入时由 Node.js 文件接口按进程当前工作目录解析。

本次决定只收口 Ticket 16 使用的 C1 条目，不推定读取缺失属性、未建模属性或 CDATA 等其它票的默认。普通覆盖写失败时不额外承诺文件内容的原子替换；已承诺的会话状态原子性仍由“写入成功后才更新路径和历史”保证。
