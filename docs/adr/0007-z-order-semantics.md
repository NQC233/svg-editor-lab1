# front/back 对应同级索引与 SVG 绘制顺序

Status: accepted (2026-10-25)

课程要求 `front`/`back` 调整同级 z-order，但没有显式写出子节点数组索引与 SVG 绘制顺序的对应关系。2026-10-25 用户确认：`front` 对应父级子节点末尾且最后绘制，`back` 对应索引 `0` 且最先绘制。

`front <id>` / `back <id>` 的规则如下：

- 图形只在其当前父级内移动，不改变父级；画布根和 `g` 容器使用同一套子节点顺序。
- `tree` 按子节点数组顺序显示；SVG 也按该顺序绘制，后绘制的内容覆盖先绘制的内容。
- `front` 把图形移到同级末尾，`back` 把图形移到同级开头。
- 移动容器时只移动容器本身的位置，整棵子树随容器移动，子树内部的兄弟顺序不变。
- 图形已在目标边界时是无操作：成功返回、不进入撤销历史、不清空 redo、不解除 IO 历史屏障。
- 撤销精确恢复原索引；重做再次移动到同级开头或末尾。

没有采用相反的索引映射，因为 SVG 的绘制顺序是文档先序，后出现的同级元素会覆盖先出现的元素；把 `front` 定义在索引 `0` 会让命令语义与可见层叠相反。
