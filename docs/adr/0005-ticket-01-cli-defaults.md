# Ticket 01 采用 CLI 与 init 补充默认

Status: accepted (2026-10-25)

Ticket 01 依赖 C1 中若干课程未逐条规定的默认，但发布时将它们保留为待确认。用户于 2026-10-25 明确要求实现 Ticket 01；本次将该实现指令记录为本票所需默认的采纳决定，不扩展到 C1 的其它条目。

本 ADR 确认：启动横幅和提示符只在标准输入是 TTY 时输出；结果、警告和错误统一写标准输出；`init` 成功后直接替换当前文档，不询问确认。`help` 列出完整目标语法并明确当前能力边界；带参数的 `canvas` 尺寸修改仍属于 Ticket 15，不在本票实现。

这样 Ticket 01 可以在不虚构历史能力的前提下交付最小命令链。代价是 C1 仍需按票拆分：无操作历史、UTF-8/路径、读取缺失属性和未建模属性等规则继续由后续票分别收口，不能由本 ADR 推定已确认。
