# 读取只接受支持子集，拒绝会改变画面的未建模结构

Status: accepted (2026-10-22)

本阶段的图形模型没有 `transform`，所有编辑命令直接修改几何坐标；画布坐标也按根元素的 `width`/`height` 像素处理。因此 `read` 只接受六种图形元素、公共样式属性和几何属性；根元素必须有正的 `width`/`height`，`viewBox` 必须缺失或恰好等于 `0 0 width height`。`transform`、`style`、会画出内容的未知元素和不匹配的 `viewBox` 都拒绝整份文件；`title`、`desc`、`metadata` 和注释忽略；不影响几何的未知属性保留用于读写往返。

这样选择是因为：保留 `transform` 会让 `move`/`scale`/`ungroup` 同时面对局部坐标和显示变换，`ungroup` 在旋转或斜切时无法用现有图形类型保真；跳过未知元素会在保存时静默丢失画面；把任意 `viewBox` 当作缩放又需要一套坐标映射。拒绝并在报告中记录为未来变化点，比读入后悄悄改变画面更诚实。

代价是编辑器不能读取所有合法 SVG。若未来要支持 `transform` 或任意 `viewBox`，需要先决定变换归属于图形还是文档，并修改几何命令和序列化；这个 ADR 应在那个时候被重新审视或取代。以 `on` 开头的事件处理器和 XML 样式表处理指令也被拒绝，避免把活动内容写回文件。
