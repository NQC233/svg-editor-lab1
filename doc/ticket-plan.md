# Phase 1 纵向任务计划

状态：19 张票的粒度与阻塞关系已于 2026-10-23 获用户批准；Ticket 01–03 已合入 `main`，Ticket 04 已在功能分支完成实现并待 PR 合入，其余票尚未开始。未决契约仍按下表保留。

依据：[规格](./spec.md)、[课程要求](../phase_cli_1.md)、[领域术语](../CONTEXT.md)和[架构方案](./README.md)。本计划取代原 [T1–T8](./tasks.md) 的执行顺序；旧内容仅作历史技术工作清单。下列编号为计划编号，GitHub 对应关系见发布索引。

## 切片原则与学习记录

- 用户选择：撤销/重做留到后续票，每票更细。第一票先交付空画布会话，第二票创建并观察矩形，第三票才开放撤销/重做。
- 比较：把创建和历史合并，能更早验证完整撤销链，但首次评审同时覆盖输入、模型和历史状态。分开可缩小每次评审范围，代价是第二票只完成创建行为，尚不满足编辑命令的最终历史验收。
- 防止返工的契约：从第一票采用命令对象和执行器，第二票创建命令通过封装的文档操作修改状态；第三票补齐创建命令的反向操作与历史接入。后续编辑票同时交付各自的撤销、重做和无操作语义，不再积累历史欠账。
- 第一票无需预建六种图形或空的 IO 接口。现有代码只有启动骨架，没有需要先独立交付的大范围重构。
- 每票只穿过自身行为需要的 CLI、应用、领域、显示或 IO 模块，并附对应测试；模块边界沿用已确认架构，不为票边界另造一套分层。
- Ticket 01 已用真实脚本回放验证最小命令链；切分收益的后续部分仍待实现验证，第三票的真实 CLI 回放仍是首次验证命令与历史边界的检查点。

## 共用验收规则

- 分支操作遵循 [项目协作规则](../AGENTS.md)：功能实现前新建并切换到 `feat/` 分支，禁止直接在 `main` 上实现功能。
- 面向对象、一类一文件、字段封装；只有命令分发和图形工厂两处按名字分派，容器和叶子使用统一操作。
- 每票附至少一条真实 CLI 成功回放和相关失败回放，断言输出及可观察状态；必要时补领域或命令测试。不得仅以假命令测试代替实际用例。
- 所有失败保持文档、当前路径和已有历史不变。第三票起，每个编辑票还验证单次撤销完整恢复、重做、redo 分支变化；存在无操作的命令验证其不记录历史、不清空 redo、不解除历史屏障。
- 图形扩展票使该类型适用于当时已经交付的命令；后续操作票覆盖所有已支持类型。通用命令不能通过类型名分支枚举图形。
- 类型、输出格式、数值边界、参数错误采用规格；受下节未决项影响的验收保留为待定，不能自行宣称 Ready。
- 每票运行适用测试及统一检查；入口变化另验开发入口与构建入口。同步报告、分步 Git 记录，最终验收票只补跨功能证据，不承接此前欠缺的测试。

## 票据

### 01 空画布命令会话

**交付：** 从终端运行 `help`、`init` 和无参数 `canvas`，可以创建、替换、查询空画布并正常退出。

**阻塞：** 无功能依赖；使用 C1 的 CLI/init 默认。

- 验收：无文档时 help 可用、canvas 报错；默认/显式尺寸、非法尺寸、参数个数和失败后画布不变均可回放。
- 验收：逐行输入、注释、引号、错误前缀、TTY/脚本输出与 EOF；help 列出完整目标语法，明确这是部分实现阶段。
- 影响模块/接口：CLI → 命令对象/执行器 → 文档尺寸；装配与输出。未来的历史接入点留在执行器。
- 风险与人工审核：终端不能直接修改领域对象；实际新增测试须被测试脚本发现。

**实现状态（2026-10-25）：** 已完成。`help`、`init` 和无参数 `canvas` 经命令对象与执行器交付；真实脚本和 TTY 模式均有测试；带参数 `canvas` 明确留给 Ticket 15。

### 02 创建并查看矩形

**交付：** `init → create rect → show/tree`，可以在画布根创建多个矩形并检查属性、顺序。

**阻塞：** 01，复用真实命令会话与当前文档。

- 验收：尺寸、坐标、可选填色、大小写敏感 id、重复 id、未知类型、缺失目标的错误；失败不改变原图形。
- 验收：根级 tree 和 show 的格式；颜色中的 `#` 不被当作注释。此票尚不提供 undo/redo，不冒充完整编辑验收。
- 影响模块/接口：创建命令、图形工厂、矩形、文档寻址/插入、显示格式化。
- 风险与人工审核：只建立当前行为需要的抽象；插入位置与创建结果必须可供后续反向操作使用，不把公开可写字段当作接口。

**实现状态（2026-10-25）：** 已完成。已实现根级矩形创建、id 索引、`tree`/`show` 和失败原子性；未提前实现 `in`、其他图形或 undo/redo。

### 03 撤销与重做矩形创建

**交付：** `create rect → undo → redo`，以及 init 前后的历史屏障。

**阻塞：** 02（已完成）；C1 无操作历史与 C2 已于 2026-10-25 收口。

- 验收：撤销后 id 不存在，重做恢复原属性和位置；一次创建一个撤销单元，新创建清空 redo。
- 验收：无文档、空栈、init 成功屏障、init 失败保留历史；显示与失败编辑不破坏 redo。
- 影响模块/接口：创建命令反向操作、执行结果、执行器、历史、undo/redo 命令。后续命令沿用这套协议。
- 风险与人工审核：历史改变发生在成功后；初始化后旧图形引用不能被历史复活。

**实现状态（2026-10-25）：** 已完成并通过 [PR #23](https://github.com/NQC233/svg-editor-lab1/pull/23) 合入 `main`（merge commit `c232787`）。`CreateCommand` 保存创建位置并提供撤销/重做；`CommandHistory` 维护 undo/redo、redo 分支清空和 `init` 屏障；命令目录每次分发创建独立命令对象，避免历史条目共享执行状态。21 个测试覆盖成功撤销重做、原位置恢复、空栈、无文档、redo 分支、失败与显示命令保留 redo、`init` 成功/失败屏障及真实 CLI 回放。

### 04 创建圆、椭圆与直线

**交付：** 三种几何叶子可创建、查看、撤销和重做。

**阻塞：** 03，复用创建与历史全链路。

- 验收：各自参数、默认样式省略、半径约束、浮点及非法数值；tree/show 格式与创建撤销精确一致。
- 影响模块/接口：图形子类、工厂、图形自己的显示描述；通用创建命令和历史协议不新增类型分支。
- 风险与人工审核：三种类型是同一扩展方式，暂合一票；若实际评审负担过大，可按类型继续分开。

**实现状态（2026-10-25）：** 已完成实现与本地验收，待 PR 合入。新增 `Circle`、`Ellipse`、`Line` 三个多态图形类及对应工厂构造；`CreateCommand`、历史、tree/show 格式化器没有新增类型分支。测试覆盖三种类型的创建、显示、撤销重做、默认样式省略、浮点/非法数值、半径约束、参数个数和失败原子性，并包含真实 CLI 回放。

### 05 创建与显示文本

**交付：** 创建带空格、中文、空内容、引号和反斜杠的文本，可查看与撤销重做。

**阻塞：** 03，复用创建与历史；无需等待 04。

- 验收：text 内容与坐标正确；tree/show 的 JSON 字符串转义、引号参数和错误输出可回放。
- 影响模块/接口：文本图形、工厂与分词结果的引号信息。
- 风险与人工审核：内容为 `in` 的带引号 token 不应被未来容器后缀误识别。

### 06 容器内创建与树形查看

**交付：** `create g`、嵌套容器和 `create … in`；tree 显示子树，show 显示父级。

**阻塞：** 03，复用图形创建、观察和历史；与 04、05 可独立推进。

- 验收：用矩形和多层容器演示创建、局部 tree、兄弟对齐；撤销/重做恢复归属与索引；后缀适用于所有已支持类型。
- 验收：不存在或非容器的目标、重复 id、非法后缀不改变树。后续类型扩展复用同一归属机制。
- 影响模块/接口：容器/叶子统一接口、文档插入和 id 索引、工厂、创建命令、显示遍历。
- 风险与人工审核：画布不是有 id 的图形；父子关系不能绕过文档操作随意修改。

### 07 平移图形与整棵子树

**交付：** move 作用于所有叶子与嵌套容器，单次撤销精确恢复整棵子树。

**阻塞：** 04、05、06，验收需要全部叶子类型及容器；使用 C1 无操作规则。

- 验收：正负增量、浮点、容器摘要、空容器与零增量；任何计算结果不合法时整条命令失败、不留下部分移动。
- 影响模块/接口：多态几何操作、几何快照、移动命令与历史结果。
- 风险与人工审核：不能靠减回增量实现精确恢复；递归中后一个图形失败不能留下前一个已修改。

### 08 缩放图形与整棵子树

**交付：** scale 按画布原点缩放各类型建模几何，支持精确撤销重做。

**阻塞：** 04、05、06；不依赖 07，两者复用已确认的几何快照契约。

- 验收：位置和尺寸按规则变化；文本只缩放坐标，stroke-width 不变；非正数、非法计算结果失败不变，因子 1 为无操作。
- 影响模块/接口：多态几何操作、几何快照、缩放命令。
- 风险与人工审核：快照设施只维护一份；并行修改共享实现可能需要协调，但不虚构功能阻塞边。

### 09 修改属性与文本内容

**交付：** set 修改几何、公共样式及文本内容，并能恢复旧值或“未设置”状态。

**阻塞：** 04、05、06，验收各类型白名单及容器公共属性；使用 C1 无操作规则。

- 验收：每类白名单、数值边界、空样式拒绝；容器样式只设置自身，不改写子图形；相同值不入历史。
- 影响模块/接口：图形属性校验与多态方法、属性命令、显示。
- 风险与人工审核：未设置与显式默认值不能混同；未知属性不能通过公共数据袋写入。

### 10 删除与恢复子树

**交付：** delete 删除叶子或容器及全部子孙，一次 undo 放回原父级和原位置。

**阻塞：** 06，需要容器、id 索引及创建历史。

- 验收：子孙 id 一起释放并恢复；兄弟顺序保持；不存在目标失败不变；重做再次完整删除。
- 影响模块/接口：文档移除/恢复、删除命令、历史。
- 风险与人工审核：保存的是完整子树和位置，不能漏恢复 id 索引；不依赖 move/scale/set。

### 11 移动图形归属

**交付：** addto 将已有图形或子树追加到容器，撤销恢复原归属。

**阻塞：** 06；使用 C1 无操作规则。

- 验收：跨父级、同父级移到末尾、已在末尾无操作；自身/子孙成环与非法目标拒绝，失败保持树和历史。
- 影响模块/接口：文档重挂、父级/索引记录、addto 命令。
- 风险与人工审核：改变归属不复制图形、不改变几何，id 索引仍唯一。

### 12 将已有图形编入新容器

**交付：** group 支持跨父级收编，并可整体撤销与重做。

**阻塞：** 06；另受 C3 阻塞，不以 addto 命令为前置。

- 验收：首目标父级与插入位置、最终确认的子图形顺序；单目标、跨父级、多目标原索引恢复。
- 验收：重复目标、缺失目标、目标同时包含容器及其子孙时全部拒绝，不留下空容器或部分摘出结果。
- 影响模块/接口：文档批量结构变更、group 命令与位置记录。
- 风险与人工审核：反向恢复须处理多个目标来自同一父级时的索引偏移；不得调用多个会各自记历史的 addto 命令。

### 13 解散嵌套容器

**交付：** ungroup 将子图形提升到原容器位置，单次 undo 恢复容器。

**阻塞：** 06；测试树可用 create/in 构造，无需等待 12。

- 验收：子图形原顺序与子树保持；空容器解散；根级容器和叶子拒绝；撤销重做精确恢复。
- 影响模块/接口：文档批量结构变更、ungroup 命令。
- 风险与人工审核：不能把课程禁止解散根级容器的约束遗漏；子图形不能重复挂接。

### 14 调整同级绘制顺序

**交付：** front/back 对叶子与容器调整同级顺序，支持撤销。

**阻塞：** 06；另受 C4 阻塞，使用 C1 无操作规则。

- 验收：用 tree 断言明确后的索引映射；容器内部不变、原位置可恢复；边界无操作不破坏 redo。
- 影响模块/接口：文档排序、front/back 命令。
- 风险与人工审核：树的排列方向与 SVG 后绘制覆盖关系不能颠倒；最终保存回放再验证可见层叠。

### 15 修改画布尺寸并建立历史屏障

**交付：** 带参数 canvas 修改宽高，保留图形并清空、锁定历史。

**阻塞：** 03，需真实创建历史来验屏障；不依赖其他编辑票。

- 验收：无参数查询不影响历史；成功修改不移动或删除图形；非法尺寸不改画布或历史；后续创建解锁且不能撤销到屏障前。
- 影响模块/接口：画布命令、文档尺寸、执行器屏障协议。
- 风险与人工审核：文档命令与无操作编辑命令的规则不能混用。

### 16 保存 SVG 与当前路径

**交付：** save 写出全部支持图形和嵌套容器，可在浏览器查看；后续无参数 save 复用当前路径。

**阻塞：** 04、05、06，需全类型树与历史；不依赖任何几何编辑或 read。

- 验收：XML 转义、根尺寸/viewBox、属性顺序、缩进、尾换行、元素计数、样式省略；带空格路径和覆盖写入。
- 验收：无路径和写入失败保留当前路径及历史；成功后更新路径并建立屏障；浏览器人工检查中文和嵌套图形。
- 影响模块/接口：save 命令、SVG 写出器、图形的序列化表示、当前路径/历史提交边界。
- 风险与人工审核：不能在文件写入成功前更新会话路径或清空历史；文件自身的失败原子替换不额外冒充已承诺验收。

### 17 读取显式 id 的 SVG

**交付：** read 接受六种图形、有显式唯一 id、仅建模属性的文件，替换文档后可 tree/show 和撤销后续创建。

**阻塞：** 04、05、06；使用 C1 读取默认，收口 C5 的解析/封装表达。不依赖 save，输入使用手写 fixture。

- 验收：零运行时依赖解析器支持声明、实体、直接文本、嵌套和约定的 CDATA；根尺寸/viewBox 校验、重复属性/不匹配标签等格式错误拒绝。
