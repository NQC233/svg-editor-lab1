# 零运行时依赖，自写 XML 解析器与命令分词器

Status: accepted (2026-10-22)

课程重点是用 TypeScript 面向对象和设计模式完成一个 SVG 编辑器，工程当前没有运行时依赖。我们决定不为 XML 解析和命令行分词引入第三方库，而是实现一个只覆盖本项目支持子集的最小 XML 解析器和双引号分词器。

这带来三方面收益：解析错误、自动补 id 警告、未知元素/属性策略和读写往返都由项目自己控制；依赖方向和模块边界保持简单；不会因为第三方解析器的对象形态而被迫做二次映射。代价是解析器需要自己的词法、实体、错误位置和边界测试，且不追求完整 XML/SVG 兼容。

曾考虑 `fast-xml-parser`、`sax` 和 DOM 实现（`jsdom`/`xmldom`）。它们能减少解析代码，但会引入运行时依赖，并把“支持子集”的判断分散到库的配置和项目的映射层。若未来需要完整 SVG 支持，应保持 `SvgReader` 作为边界，在它内部替换解析器，而不是让领域层依赖某个库。
